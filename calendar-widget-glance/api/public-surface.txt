# Public surface of `calendar-widget-glance` — 65 declarations.
#
# This module is in `apiValidation.ignoredProjects`, so `apiCheck` registers no dump task for it and
# **no signature change here is visible to any gate**. This file is the substitute: the surface
# becomes something a reviewer sees a diff of, instead of something nobody looks at. Checked by
# `.github/scripts/check-widget-glance-surface.sh`.
#
# **Adding a line is a reviewed decision — write the reason next to it.** The list is deliberately
# explicit rather than a count, because a count can be satisfied by removing one thing and adding
# another; a list forces each name to be looked at.
#
# Two gates protect this module, and they catch different things:
#   * `check-widget-glance-surface.sh` — this list. Catches an *added* declaration.
#   * `check-consumer-resolution.sh` — compiles `.github/consumer-check` against the published
#     artifact. Catches a *removed* one, and a dependency-scope mistake.
# Neither catches a *changed signature*, and neither can: that is what `apiCheck` is for, and it does
# not run here. CHANGELOG.md is therefore the only place a consumer learns about a signature change.

# ── Fonts. `HijriWidgetFonts` is the whole per-field font option; its `default` is what a host
# writes at startup to change the face any widget renders with. It is one data class rather than a
# parameter on each widget because the receivers are declared by THIS module's manifest, so a host
# places the shipped widgets and cannot hand them per-instance state — a process-wide default is the
# only seam available without making every host re-declare all four receivers.
#
# It is a family NAME and not a font resource, and that is Glance's limit rather than a choice:
# `androidx.glance.text.FontFamily` has only `FontFamily(String)` and applies it as a `TypefaceSpan`,
# which resolves through the system font manager. A font bundled in the host's `res/font/` — including
# one shipped via Compose Multiplatform `composeResources` — is app-private and therefore invisible to
# that lookup, so it silently falls back to the system face. Only downloadable and system-installed
# fonts resolve. The KDoc says so at length, because "I set it and nothing changed" is otherwise a
# silent no-op with no error to grep for.
#
# Its four fields, not eight, because they are the slots a host actually wants to differ: the Hijri
# month/year title, the Gregorian one, weekday names, and day figures. They cover every widget — the
# grid header, weekday row and both lines of every cell; the Today strip's two halves; the three lines
# of each 1x1 tile; and the dual tile's header band, sub-row and weekday. The Android 12-14 `previewLayout` mirrors are static XML and cannot
# read a runtime value, so they keep their declared `android:fontFamily`; only the live widgets and the
# Android 15+ `providePreview` trees honour it.
HijriWidgetFonts
HijriWidgetFonts.public
